
# Simple Interest Calculator

## Project Description
This project calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal * Rate * Time) / 100

## Inputs
- Principal: Initial amount of money
- Rate: Annual interest rate in percentage
- Time: Time period in years

## Example
Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 * 5 * 2) / 100 = 100

## Technology Used
- Bash scripting
- Git and GitHub

## How to Run
Run the simple-interest.sh script in a Bash terminal and enter the required values.
