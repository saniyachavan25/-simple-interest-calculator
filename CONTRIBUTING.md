
# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project.

## All Contributions Welcome
All contributions are welcome, including:
- New features and enhancements
- Bug reports and bug fixes
- Documentation improvements
- Suggestions and ideas

## How to Contribute
1. Fork the repository.
2. Clone your fork to your computer.
3. Create a branch for your changes.
4. Make and test your changes.
5. Commit your changes with a clear message.
6. Push your branch to GitHub.
7. Open a pull request describing your changes.

## Reporting Bugs
Describe the issue, steps to reproduce it, and the expected result.

## Code Improvements
Write clear, readable code and test your changes before submitting them.

Thank you for helping improve this project!
